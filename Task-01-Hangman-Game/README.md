# Task 01: Hangman Game

## Overview
The Hangman Game is a classic word-guessing project built using Python. It helps strengthen logic, user interaction, and game flow design.

## Skills Demonstrated
- Python basics
- loops and conditionals
- string handling
- random selection
- user input validation

## Project Goal
Create a simple game where the player guesses letters to reveal a hidden word before the allowed attempts are exhausted.

## Outcome
This task helped improve problem-solving and interactive program design using core Python concepts.
