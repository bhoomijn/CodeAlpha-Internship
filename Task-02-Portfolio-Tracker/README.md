# Stock Portfolio Tracker

A practical Python-based portfolio management tool designed to help users track and monitor their stock investments in a simple and efficient way.

## Overview
The Stock Portfolio Tracker is a beginner-friendly project built to demonstrate how Python can be used for real-world data tracking and basic financial management. It focuses on organizing user data, performing calculations, and building a simple command-line workflow.

## Project Objective
To create a lightweight application that helps users:
- store stock holdings
- track current investment value
- calculate total portfolio worth
- manage investment data in an organized way

## Problem Solved
Many beginners learn Python through small games and utility scripts, but this project highlights a more practical application: using Python to manage real-world information in a finance-focused context.

## Key Features
- Add stock entries
- Store company name and quantity
- Track holding value
- Calculate total portfolio value
- Maintain organized data with Python structures
- Use a simple command-line interface

## Tech Stack
- Python
- Lists and dictionaries
- Basic arithmetic logic
- CLI-based user interaction

## Example Workflow
1. The user enters stock details.
2. Data is stored in Python structures.
3. Values are calculated based on the entered information.
4. The system displays the current portfolio summary.
5. The user can continue updating or reviewing holdings.
